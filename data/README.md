# Generated data

This directory is for generated datasets and related small documentation.

| Path         | Purpose                                                    |
| ------------ | ---------------------------------------------------------- |
| `raw/`       | Generated raw history (gitignored).                        |
| `processed/` | Cleaned / featurized datasets (gitignored).                |
| `generated/` | Other generated outputs (gitignored).                      |

Files tracked in this directory are intentional documentation or small test
fixtures. Generated datasets and model artifacts are never committed; see
`docs/contracts.md` for the artifact contracts.
